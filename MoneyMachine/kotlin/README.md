# Money Machine — Kotlin

Règles du kata : voir [../kataRules.md](../kataRules.md).

## Stack

- Kotlin 2.4, Java 25, Gradle (wrapper), kotlin-test (JUnit 5)

## Fichiers

- `src/main/kotlin/Main.kt` : point d'entrée
- `src/main/kotlin/MoneyMachine.kt` : code du kata
- `src/test/kotlin/MoneyMachineTest.kt` : tests TDD

## Commandes

```sh
./gradlew test   # lancer les tests
./gradlew run    # lancer le main
```
