# Money Machine — Python

Règles du kata : voir [../kataRules.md](../kataRules.md).

## Stack

- Python 3.14, pytest, environnement géré par [uv](https://docs.astral.sh/uv/)

## Fichiers

- `main.py` : point d'entrée
- `money_machine.py` : code du kata
- `tests/test_money_machine.py` : tests TDD

## Commandes

```sh
uv sync                # créer / mettre à jour le venv (.venv)
.venv/bin/pytest       # lancer les tests
.venv/bin/python main.py  # lancer le main
```
