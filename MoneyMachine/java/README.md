# Money Machine — Java

Règles du kata : voir [../kataRules.md](../kataRules.md).

## Stack

- Java 25, Maven, JUnit 6

## Fichiers

- `src/main/java/moneymachine/Main.java` : point d'entrée
- `src/main/java/moneymachine/MoneyMachine.java` : code du kata
- `src/test/java/moneymachine/MoneyMachineTest.java` : tests TDD

## Commandes

```sh
mvn test                                                  # lancer les tests
mvn compile && java -cp target/classes moneymachine.Main  # lancer le main
```
